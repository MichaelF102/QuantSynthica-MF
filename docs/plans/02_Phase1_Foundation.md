### Schema (Alembic migration 0001)
`amcs`, `fund_categories`, `schemes` (canonical: base_fund grouping), `scheme_plans`, `scheme_options`, `fund_snapshots`, `external_ids` (Yahoo symbol, later AMFI code/ISIN), `ingestion_runs`, `data_quality_issues`. Primary keys are internal IDs; Yahoo symbol is a unique **external** ID.

### CSV ingestion
- [ ] Bronze: copy original CSV + record row count, hash, ingest timestamp.
- [ ] Parse with explicit dtypes; handle BOM (file starts with a UTF-8 BOM).
- [ ] Keep `Unspecified` plan (975) and option (415); never infer.
- [ ] Flag `is_insurer_fund`, `is_discontinued`; store `n_share_classes`, group by `base_fund`.
- [ ] Null handling: Net Assets 1,067, Initial Investment 406, Market Cap 32, YTD/3M 1 each. Keep nulls; never impute silently.
- [x] Validation rules (R0xx in `yahoo_csv.py`): errors quarantine the row (kept, flagged); warnings only flag. Rules written to `data_quality_issues`. Note: an earlier claim of a 50-day average of 6,314 on a ₹31.92 fund was a misreading of sampled values; no such row exists.
- [ ] `split` column stored for audit only, excluded from API feature fields.
- [ ] Idempotent: second run yields 0 inserts.
